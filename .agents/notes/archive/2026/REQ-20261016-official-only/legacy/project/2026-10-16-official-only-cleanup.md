## 1. 当前事实与边界

- 官方服务位于 `src/jx3_bot/`，已有 QQ WebSocket／HTTP、天气、四表聊天历史和离线测试；未获得真实 QQ／天气平台联调结果。本次请求授权清除旧代码，不等于授权联网启动或宣告生产切换成功。
- 工作区在本轮前已有大量暂存／未暂存／未跟踪内容，包含旧入口、插件、环境配置和官方服务文件。旧 `bot.py`、`src/plugins/`、`requirements.txt`、`pyproject.toml` 的 `[tool.nonebot]` 仍能误导部署；官方运行链路不依赖它们。
- 旧复读、AI 与爬虫不是官方服务已具备的功能；删除不意味着迁移。`src/plugins/weather/docs/` 两份天气参考资料不是插件运行代码，须移到 `docs/weather/` 保存来源及历史属性。
- `.env.prod` 有原有暂存改动、根目录历史密钥文件已有工作树删除而索引仍有条目；不读取／传播真实凭据、不擅自清理 Git 历史或运行环境。旧配置和私钥的安全治理需单独核实并轮换。旧环境配置仅从工作树移除，已有索引状态需维护者检查。

## 2. 目标、非目标与验收

- 目标：仅保留 `python -m jx3_bot` 官方运行入口与 uv 官方依赖；移除旧入口、旧插件源码、旧依赖清单和 NoneBot 元数据；文档、示例与开发约定不再指导启动旧客户端；保留历史方案作为历史而非当前事实。
- 非目标：恢复旧 AI／复读／爬虫业务、真实平台联调、迁移／重建现有 SQLite、变更官方 API 行为或重写历史提交。旧生产配置及任何凭据不自动导入新配置。
- 验收：官方包／测试无 NoneBot／OneBot 运行导入，旧启动路径与依赖配置不留在当前工作树；离线套件、CLI 帮助、锁文件一致性和文档链接检查通过；正式上线状态如实记录。
