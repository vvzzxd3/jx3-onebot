# 单聊天气请求无响应排查

> 本文保留当时仅群业务的排查事实；维护者随后授权群／单聊通用匹配，现已实现单聊天气与官方C2C回复，详见[后续实现](<../../../REQ-20261011-matcher-templates/legacy/qq-integration/2026-10-11-matcher-templates.md>)。下文“单聊不支持／待授权”不是最新状态；真实联调仍未执行。

- 所属模块：QQ 官方接入
- 建档日期／最近更新：2026-10-11（Asia/Shanghai）
- 状态：排查完成；原因由静态代码与合成事件验证，96项离线回归通过；未修改业务支持范围，真实群回复未验证。
- 需求来源：维护者提供单聊天气请求接收日志、同秒 `ignored / unsupported_event` 分发日志及随后 `op=11` 接收摘要，要求排查无响应原因。不复制真实OpenID、trace或用户正文。
- 关联：[控制台日志实现](<2026-10-11-console-observability-plan.md>)、[部署指南](<../../../../../../../docs/qq-integration/2026-10-10-deployment.md>)。

## 1. 背景与当前事实

- `[receive] [单聊]` 说明进程已观察到单聊消息；[聊天展示](<../../../../../../../src/jx3_bot/observability.py#L241-L264>) 仅将 `C2C_MESSAGE_CREATE` 标为单聊。
- [事件过滤](<../../../../../../../src/jx3_bot/integrations/qq/events.py>) 只允许 `GROUP_MESSAGE_CREATE`、`GROUP_AT_MESSAGE_CREATE`。单聊在命令解析、身份校验、时间校验之前返回 `MessageDecision(None, "unsupported_event")`。
- [网关分发](<../../../../../../../src/jx3_bot/gateway.py#L156-L167>) 使用上述过滤结果；[持久化接受](<../../../../../../../src/jx3_bot/store.py#L178-L201>) 对message=None只推进会话水位，不创建inbox命令，返回ignored；[分发日志](<../../../../../../../src/jx3_bot/gateway.py#L115-L129>) 输出过滤原因。
- [应用处理](<../../../../../../../src/jx3_bot/application.py#L16-L30>) 只处理已入队命令，所以此单聊请求不会触发天气查询、outbox或QQ回复。这是当前未实现单聊业务的结果，不是本条请求调用天气后失败。
- [心跳处理](<../../../../../../../src/jx3_bot/gateway.py#L137-L140>) 将op=11视为ACK，清除待确认状态；[接收摘要](<../../../../../../../src/jx3_bot/observability.py#L270-L286>) 与 [事件名白名单](<../../../../../../../src/jx3_bot/observability.py#L309-L313>) 对没有t的控制帧显示unknown，对没有s的字段使用安全占位。unknown／hidden不代表心跳错误。
- [README](<../../../../../../../README.md#L72>) 与已批准日志方案明确：单聊只展示，不处理天气业务。未知用户是昵称缺失／空串的展示占位，不是拒绝原因。

以上依据是维护者日志与当前工作区源码；未检查运行进程、部署版本或原始事件。不能据此宣称群回复、天气鉴权、QQ权限及持续网络连接已验证成功。

## 2. 目标、非目标与验收

- 目标：解释收到消息但无响应的原因，区分业务过滤和心跳，提供下一步。
- 非目标：不新增单聊回复、不修改intents／配置／数据库／命令，不读取真实凭据，不启动服务或调用QQ／天气受保护API。
- 验收：合成相同正文的单聊／群聊输入验证过滤差异；既有测试覆盖过滤前展示且不入队；记录实际结果与限制。

## 3. 方案与关键决策

按排查范围留存结论，不将打印单聊误认为支持单聊天气。不只把C2C加入白名单：当前 [消息模型](<../../../../../../../src/jx3_bot/integrations/qq/models.py>)、群身份校验、持久化键及HTTP回复链路均是群模型。若需单聊业务，应另行核实官方事件／回复接口与应用权限，设计会话类型、去重及FIFO隔离、偏好作用域、回复路由与旧数据库兼容迁移，保持月计数及保守发送语义。
