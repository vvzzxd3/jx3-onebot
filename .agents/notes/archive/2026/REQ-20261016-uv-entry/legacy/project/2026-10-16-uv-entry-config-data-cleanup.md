## 1. 背景与当前事实

[项目配置](<../../../../../../../pyproject.toml>)禁止安装本项目，现有命令需要 `PYTHONPATH=src` 和专用 uv 环境；[CLI](<../../../../../../../src/jx3_bot/__main__.py>)要求显式传入子命令。[当前配置模板（旧文件当时所在位置）](<../../../../../../../.env.production.example>)和[默认数据库路径](<../../../../../../../src/jx3_bot/config.py>)均带 `official`。现有 SQLite 包含持久状态，代码还依赖预算、消息传输队列及聊天历史；截至建档检查时旧数据库是 1,921,024 字节，旧位置无 WAL/SHM，`lsof` 对该路径没有列出占用者。此处不声称真实 QQ 运行已验收。

## 2. 目标、非目标与验收条件

- 目标：默认 `uv run jx3_bot` 启动服务，辅助命令保留；使用 `.env.production` 与 `.env.test` 命名、配套无密钥示例；保持凭据内容不可见；保守地将现有 SQLite 迁移至 `data/bot.sqlite3` 并更新默认路径；清理可证实无关的生成物与旧专用运行环境／导出命名。
- 非目标：实际连接 QQ／天气受保护接口、读出生产配置和数据库业务正文、清空预算／聊天历史／队列、抹除 Git 历史、改写历史实施结论或删除仍使用的密钥目录。
- 验收：新命令存在且 `--help` 离线可用；命令无参数按 run 分派的行为有合成测试而不真实联网；数据库迁移前后 `integrity_check`、表计数及标识一致；完整离线测试与锁文件、导出清单、文档链接通过；源数据和配置不泄露。

## 3. 方案摘要与关键决策

使用 setuptools 显式安装 `src/jx3_bot` 并注册 `jx3_bot` console script，打包天气模板。uv 改用默认 `.venv`；现有 `.venv-official-uv` 暂保留到新环境验证通过后再清理。生产配置采用旧私有文件仅重命名为 `.env.production`，程序默认加载该路径；测试配置只提供 `.env.test.example`，离线测试仍用临时环境，不提交真实 `.env.test`。`requirements-official.txt` 作为兼容导出改名而不更改依赖事实来源。

数据迁移先复核无占用、目标路径不存在；对旧库做只读完整性和不涉及内容输出的元数据核验及一致快照备份；迁移前后核对；失败时保留原始文件并停止，不自动清空月预算。维护者虽允许迁移不可行时新建空库，但必须先清楚记录原因与重置后果。
